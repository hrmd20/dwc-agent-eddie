# Reaction styles inside EDDIE MASTER EDITOR

Both formats support the [doctor cutout and source-video overlay](reaction-cutout.md). Follow the selected format and the approved edit.

- **EDDIE Sync Reaction**: rounded source-video overlay with original source audio, then full-screen doctor commentary and audio. Read [Sync Reaction](reaction-sync.md). Use when the doctor is visibly reacting as the source plays.
- **EDDIE Async Reaction**: source excerpt first, then separately recorded full-screen doctor commentary, with optional supporting images or study excerpts below EDDIE captions. Read [Async Reaction](reaction-async.md). Reference: https://www.instagram.com/reel/Dd46Pe2COyK/.

Select Sync for visible live reactions or an explicit Sync request. Select Async for a source-first edit with separately recorded commentary. For an unspecified new reaction request, use Async when the footage supports that sequence. Do not turn a supplied synchronized composite into Async without direction. If the intended timing is unclear from footage or brief, ask one focused question. A script alone supports planning, not a claim that video has been rendered.

Both use Master Editor's measured −14 LUFS loudness target with peak protection. Sync retains its existing reaction-specific caption treatment; Async uses the original EDDIE captions. Current user directions override either default.
