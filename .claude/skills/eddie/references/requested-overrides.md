# Requested visual revisions

These are opt-in treatments, not new defaults for every video. Preserve the approved five-mode style unless the user requests a change.

- **Reference hook:** match supplied wording, line breaks, visible font weight/size, background shape and normalized position. A supplied three-line all-black example overrides the default two-line/red style. Record duration explicitly; “throughout” means the full retained video, not three seconds. Do not claim an exact font identity from appearance alone.
- **Start on a phrase:** inspect the source around the approximate timestamp and cut just before the complete requested phrase. Do not cut blindly at the rounded second. Preserve existing captions/images/audio in an already-edited source unless asked to replace them.
- **Full-screen still:** preserve the existing cue interval unless told otherwise. Fill the target aspect ratio using a proportional cover crop, not stretching. Keep the important subject visible; use the highest-resolution supplied original. Clarify overlay precedence only when ambiguous; a request to cover the entire frame can cover the existing hook/captions as well. Never crop clinical label details that are essential to the intended visual without flagging it.
- **Transparent product cutout:** prefer the supplied asset, preserve label text and appearance, inspect alpha/edges, and save the selected asset inside the project. Verify that no old burned-in product remains underneath.
- **Slide and whoosh:** only when requested. Record entry direction, hold, exit direction and sound timing; synchronize to the spoken cue. For “enter left, exit left,” both movements use the left edge. Keep effect volume below speech and preserve clipping protection. This does not enable motion/sound on other images.
- **Repeated product row:** use the requested count, equal spacing and consistent size, below captions and clear of the face. It is a visual illustration; do not add unsupported dosing labels.
- **Numbering:** resolve “Video 3/4” against the latest user-facing review list, not an internal project folder name. If title and quoted speech conflict, check transcripts and ask one focused clarification before changing the wrong video.

Inspect actual encoded frames at the changed cues. Keep edits versioned and separate a supplied social-post caption from burned-in speech captions. Do not upload or publish merely because a review file was created.
