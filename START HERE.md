# Welcome to EDDIE

Turn your practice's recordings into edited videos. You provide the footage; EDDIE helps choose the style, adds captions and prepares a preview.

## Start in 3 steps

1. **Download and unzip.** On GitHub, choose Code → Download ZIP, then open the downloaded ZIP. Keep the extracted folder together.
2. **Open the extracted folder in your AI editing assistant.** Use an assistant that can read this folder and run local editing tools, such as Codex or Claude Code. A normal browser chat or opening GitHub alone is not enough. If you do not have a compatible assistant, have your practice's technical helper set one up first.
3. **Paste the message below.** EDDIE will check the tools, explain any missing setup and ask for your recording and where to save the result.

> Read AGENTS.md and ONBOARDING.md in this folder. Help me make my first EDDIE video. Check what is ready on this computer, explain anything missing in plain language, and recommend a style from my footage. Start with a short preview before making the full video.

**Prefer a visual guide?** Double-click `START HERE.html` in the extracted folder. It opens a guide in your browser; it does not install software or start an edit.

## What should I give EDDIE?

- Your video file, or its location on your computer.
- Where you want the edited video saved.
- Any wording, images or cuts you already want. These are optional.

You can simply say: **“Here is my video. Choose the best EDDIE style and show me a short preview.”**

A script alone is enough to plan an edit. EDDIE needs your footage to make your video. For Rapid Fire, tell it whether the questions are already recorded, asked by a nurse, or need a requested AI voice.

## Pick a style—or let EDDIE choose

| If you want… | Ask for… |
| --- | --- |
| A clean doctor-to-camera video with captions and an opening title | Captions + hook |
| Pictures illustrating what the doctor discusses | Captions + images + hook |
| Quick questions, yes/no answers or ratings out of 10 | Rapid Fire |
| The doctor reacting in a corner while another clip plays | Sync Reaction |
| Another clip first, followed by the doctor's full-screen response | Async Reaction |

These five styles are inside **EDDIE MASTER EDITOR**. It uses 200% audio gain once with peak protection; you can request a different volume. All five styles include a 3-second top-centered title: maximum two lines, white rounded box, black text/red emphasis and equal padding. You can request no title.

Also available: **Landscape** for horizontal videos and **Carousel** for Canva slides using your own editable template.

## Your first edit

1. EDDIE checks the recording and available editing tools.
2. It recommends a style and explains the plan briefly.
3. For your first edit, ask for a 10-second preview or storyboard. Review framing, captions and images before spending time on the full export.
4. Say **“Make the full video”** when you like the preview. Give specific feedback such as “Move the captions higher” or “Use Async Reaction.”
5. EDDIE saves a new video in your chosen folder and gives you a link. Your original recording stays intact. Posting to social media is a separate request and needs your connected account.

If you already know what you want, you can request a full edit immediately.

## What the download includes

EDDIE is a set of reusable editing instructions and presets for an AI assistant. **The ZIP is not a standalone video editor.** Downloading it does not automatically launch a welcome chat, install editing tools or connect your social accounts.

Your assistant checks for video inspection/export tools, transcription and caption rendering before editing. Some computers need one-time setup. EDDIE should explain the exact missing step; do not paste passwords or API keys into a public GitHub issue. Your AI assistant or optional services may have their own costs; this download includes no account credits.

## Stuck?

- **“EDDIE isn't recognized.”** Ask: “Read `.agents/skills/eddie/SKILL.md` in this folder and follow it for my video.” Claude Code can use the matching `.claude/skills/eddie/SKILL.md`.
- **The assistant cannot see my video.** Attach it using your assistant's file picker or give it the correct local path and grant access when prompted.
- **An editing tool is missing.** Ask: “Tell me exactly what needs installing for this edit and help me set it up.”
- **Only have a script?** Ask for the style recommendation and recording plan first.

Keep recordings, transcripts and exports in private project folders, not in the public GitHub repository. Use footage your practice is authorized to edit and share.
